# QC検定2級 ドリル

品質管理検定（QC検定）2級の学習用Webアプリです。ブラウザだけで動き、インストールは不要です。

- 公式の品質管理検定レベル表（Ver.20150130.2）に問題を対応づけ。2級欄103項目と1対1、2級の範囲に含まれる3級欄・4級欄のうち2級欄と重複しない61項目も含めて全164項目、各項目3問以上。【】の出題レベルも表示。4級範囲の用語は「品質管理検定（QC検定）4級の手引き」Ver.3.2 に合わせている資料タブで項目ごとの問題数と正答率を確認し、その項目だけを演習できる
- 知識問題 430問（手法9分野・実践7分野。実践には4級の「企業活動の基本」を含む）
- 本試験形式の問題 46題（291問）。本文の空欄をタップして選び、すべて埋めてからまとめて採点する（○×は文ごとに選ぶ）。大問の穴埋めと正誤判定。選択肢群（ア〜）から選ぶ実際の試験と同じ形式。計算が連鎖する複合大問（検定→推定、管理図→工程能力→不適合品率など）と実践の事例問題を含む
- 計算問題 64種。出題のたびに数値が変わるので、何度でも解けます
- 選択肢の偏り対策：知識問題は「一番長い／短い選択肢を選ぶ」と正答率が約25%／約19%（4択の偶然と同程度）になるよう長さを調整。否定形の設問は約24%。計算問題は正解が選択肢の何番目の大きさになるかを毎回ランダムにしている（`tests/lenbias.js`、`tests/calcbias.js` で計測）
- 模擬試験の途中保存と再開：解答するたびに保存し、アプリが閉じられてもホームの「続きから再開」で戻れる（残り時間は実時間で進む）。通常の演習は短いので保存せず、途中でやめるときは進み具合がリセットされることを確認してからやめる
- 電卓と数値表：解答中に √・二乗・メモリ付きの電卓を開ける。数値表は問題に合う表（t・χ²・F・正規分布・管理図係数・符号検定）で開き、解答後は使うマスを強調する
- 解説は要点（最初の1文）と「詳しく」の2段。間違えたときは詳しくを開いた状態で表示
- 間隔反復の復習：正解するたびに次の出題までの間隔を延ばし（1日→3日→7日→…）、間違えた問題は今日の復習に戻す。ホームの「今日の復習」と、レッスン・全分野10問に自動で混ざる
- 解説の図：正規分布の上側確率、工程能力、管理図、OC 曲線、バスタブ曲線、直列・並列の信頼度、パレート図、散布図と回帰、両側検定の9種を、問題の内容に応じて表示
- 初回起動時の案内（受験日・1日の目標・文字サイズとテーマ・通知）。設定からもう一度表示できる
- 学習ロード：4級の基本から2級の総仕上げまで8章のストーリー仕立て。ステージ（10問×2回、7割以上）をクリアして進み、章末テスト（15問・8割以上）で次の章へ。分かっている章は飛び級テストで一気に進める。最終章は模擬試験の合格で修了
- 連続記録：1日の目標（5〜30問）を解いた日を数える。7日続けるごとに「記録の保護」が1つたまり（最大2つ）、できなかった日を1日だけ埋める
- 設定（右上）：テーマ（端末に合わせる／ライト／ダーク）、文字サイズ（4段階）、効果音（Web Audio で合成）、バイブレーション、1日の目標、受験する回（公式発表の回、または日付を指定）、毎日のリマインダー通知（Android アプリ版）、更新履歴
- 画面構成：下部ナビ（ホーム／ロード／演習／成績／資料）。問題を解いている間はナビを隠し、下部の確認バーで解答する。Android の戻るボタンで前の画面に戻る
- 解説欄の「誤りを報告」でメモを残し、成績タブで一覧・コピーできる。解答記録はテキスト（JSON）で書き出し・読み込みでき、アプリ版と Web 版の間でも移せる
- 選択して「確認する」で判定する方式。正解・不正解は効果音で知らせます（右上でオン・オフ）
- 間違えた問題は、2回続けて正解するまで優先的に出題されます
- 分野別の正答率と、演習ごとの正答率の推移（p管理図形式）を表示します
- 模擬試験：50問（手法30・実践20）、90分。合格基準（各分野 概ね50%以上、総合 概ね70%以上）で判定します
- 資料タブ：公式ページ（レベル表・合格基準・問題例・基準解答・4級用テキスト）、分野ごとの関連JIS、過去問題集の案内。解説の下の「資料を見る」から関連規格に移動できる
- 数値表：正規分布、t分布（両側）、χ²分布、F分布（5%・2.5%）、管理図係数（A2・D3・D4・d2・A3・B3・B4）、符号検定表

出題範囲は日本規格協会「品質管理検定レベル表（Ver.20150130.2）」の2級に合わせています。`node tests/test.js` は、レベル表のどの項目にも問題が1問以上あることを検査します。

## 使い方

`docs/index.html` をブラウザで開くだけで使えます。GitHub Pages で公開すれば、スマートフォンからも使えます。

進捗（解答記録・模擬試験の履歴）はブラウザの localStorage に保存されます。端末やブラウザを変えると引き継がれません。

## Android アプリ（APK）

[Releases](../../releases) から `qc2-drill.apk` をダウンロードしてインストールします。Google Play を経由しないため、初回はブラウザやファイルアプリに「不明なアプリのインストール」を許可する必要があります。

- 中身は Web 版と同じです（`docs/index.html` を WebView で表示）。問題を解くのはオフラインでも可能で、フォントだけはネット接続時に読み込みます。
- 進捗はアプリ内に保存されます。アプリを削除すると消えます。
- 新しい版は上書きインストールでき、進捗は引き継がれます。

APK は GitHub Actions（`.github/workflows/android.yml`）でビルドします。`main` への反映ごとに Actions の実行結果（Artifacts）に、GitHub の画面でリリースを公開すると、そのリリースに APK が添付されます。

署名鍵はリポジトリに入れていません（第三者が同じ署名の偽 APK を作れないようにするため）。APK は、このリポジトリの Releases から入手したものだけをインストールしてください。

### 自動ビルドの署名設定（作者用）

GitHub Actions で APK を作るには、リポジトリの Settings → Secrets and variables → Actions に次の4つを登録します。

| 名前 | 内容 |
|---|---|
| `KEYSTORE_BASE64` | 署名鍵ファイルを Base64 にした文字列 |
| `KEYSTORE_PASSWORD` | 鍵ストアのパスワード |
| `KEY_ALIAS` | 鍵の別名 |
| `KEY_PASSWORD` | 鍵のパスワード |

鍵ファイルを Base64 にしてクリップボードへ入れる（Windows PowerShell）：

```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes("$HOME\Documents\qc2.keystore")) | Set-Clipboard
```

手元でビルドする場合は、`android/keystore.properties`（.gitignore 済み）に `storeFile`・`storePassword`・`keyAlias`・`keyPassword` を書きます。

### リマインダー通知（Android）

- 設定でオンにした時刻に、その日の目標問題数をまだ解いていなければ通知します。達成済みの日は通知しません。
- 権限：`POST_NOTIFICATIONS`（Android 13 以降はオンにしたときに許可を求めます）、`RECEIVE_BOOT_COMPLETED`（再起動後に予約し直すため）。正確なアラームの権限は使わないので、数分ほど遅れることがあります。
- 実装：`Reminder.java`（予約と通知）、`Bridge.java`（Web から `window.QC2App` として呼ぶ機能）。

  bank6.js        知識問題（4級の手引きの内容）
  bank7.js        知識問題（否定形の設問、抜取検査・信頼性などの補強）
  gen.js          計算問題ジェネレータ（基本）と共通関数
  gen2.js         計算問題ジェネレータ（追加）
  gen3.js         計算問題ジェネレータ（レベル表との差分）
  dai.js          本試験形式の問題（大問の穴埋め・正誤）
  dai2.js         本試験形式の問題（レベル表との差分）
  dai3.js         本試験形式の問題（複合大問・実践の事例）

## 開発

必要なもの：Python 3（scipy）、Node.js

```powershell
# 数値表を作り直す場合のみ
python tools/gen_tables.py

# ビルド
python tools/build.py

# テスト
node tests/test.js
python tests/verify.py
python tests/verify_dai.py
python tests/verify3.py
```

`src/` を編集したら `python tools/build.py` を実行し、`docs/index.html` も一緒にコミットしてください。

### 問題の追加

知識問題は `src/bank2.js` に次の形式で追加します。選択肢は先頭が正解で、表示時にシャッフルされます。

```js
['分野キー', '問題文', ['正解', '誤答1', '誤答2', '誤答3'], '解説'],
```

分野キーは `src/bank.js` 末尾の `CATS` を参照してください。

計算問題は `src/gen2.js` に、`{q: 問題文, ch: [正解, 誤答...], ex: 解説}` を返す関数として追加します。正解は必ずアプリ内の数値表（`normUp`・`tVal`・`chiVal`・`fVal`・`CC`）から計算してください。表の値と正解がずれないようにするためです。

## 注意

- 本アプリは個人が作成した非公式の学習教材です。日本規格協会・日本科学技術連盟とは関係ありません。
- 「QC検定」は一般財団法人日本規格協会の登録商標です。
- 問題と解説はすべてオリジナルで、過去問題は使用していません。
- 解説中の規格の条項内容は、作成者の知識に基づくものです。最新の規格原文で確認してください。
